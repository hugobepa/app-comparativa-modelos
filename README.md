# LLM Compare

Comparativa de modelos LLM para desarrollo de software: precios, benchmarks y recomendaciones.

## 🚀 Características

- Comparación de modelos de lenguaje (Claude, GPT, Gemini, etc.)
- Calculadora de costos por tokens
- Benchmarks de rendimiento
- Recomendaciones por perfil de uso

## 🛠️ Tecnologías

- [Astro 6](https://astro.build/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Bun](https://bun.sh/)

## 📦 Instalación

```bash
bun install
```

## 🧞 Comandos

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `bun install`             | Instala dependencias                             |
| `bun dev`                 | Inicia servidor de desarrollo en localhost:4321  |
| `bun build`               | Construye el sitio para producción en ./dist/    |
| `bun preview`             | Previsualiza la build localmente                 |

## 🌐 Despliegue

El proyecto está configurado para desplegarse automáticamente en GitHub Pages mediante GitHub Actions.
